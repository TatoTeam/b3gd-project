## What is it?

Core for an FNF=Styled rhythm game in godot, designed to be easy to work off and expand.
Originally designed for [Beta 3](https://gamebanana.com/mods/639119), but cleaned up and expanded for generic use with an example project provided.

## Why use it?

B3GD is made to have a really small footprint, and to overall be something you can work with instead of working around.
Each part is written to be as digestible as possible, trying to lose a lot of the jank that comes with Legacy FNF.
If you don't like any part of the engine, you can remove it and replace it easily - input system, note rendering, chart editor, event playing, character scripts...

## Includes
- Song playback, including note input & rendering, character animations, 
- Intuitive, fully featured chart editor, including live preview of events.
- Support for both Modcharts & Multikey
- Everything Godot includes (This may seem obvious, but keep in mind a lot of things Godot includes are far above what's provided by the 'usual' Flixel + Haxe workflow)
